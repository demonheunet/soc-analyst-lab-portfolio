# SQL Lab: Modifying Table Data Using UPDATE Statements

## Overview
This repository documents practical database administration tasks focused on data modification (`UPDATE`) within a relational `Instructors` database. It demonstrates modifying individual attributes, targeting rows via specific search criteria (`WHERE` filtering)[cite: 11, 12, 13], and updating multiple columns simultaneously in a single transaction.

---

## Target Table: `Instructor`

| Column | Key Type | Description |
| :--- | :--- | :--- |
| `ins_id` | Primary Key | Unique numeric identifier for the instructor[cite: 11, 12, 13] |
| `lastname` | Attribute | Instructor's surname[cite: 11, 12, 13] |
| `firstname` | Attribute | Instructor's first name[cite: 11, 12, 13] |
| `city` | Attribute | Current municipality of record[cite: 11, 12, 13] |
| `country` | Attribute | Two-letter country code (e.g., `CA`, `US`, `BD`)[cite: 11, 12, 13] |
