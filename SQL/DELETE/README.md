# SQL Lab: Record Removal Using the DELETE Statement

## Overview
This repository documents practical execution of data removal operations using the SQL `DELETE` statement within the `Instructors` database. It demonstrates targeted row removal using conditional filtering (`WHERE`) and analyzes database execution feedback when evaluating non-existent records.

---

## Target Table: `Instructor`

| Column | Key Type | Description |
| :--- | :--- | :--- |
| `ins_id` | Primary Key | Unique numeric identifier for the instructor |
| `lastname` | Attribute | Instructor's surname |
| `firstname` | Attribute | Instructor's first name |
| `city` | Attribute | City of residence |
| `country` | Attribute | Two-letter country code |
